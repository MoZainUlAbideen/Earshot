# Earshot

Ask questions across podcasts and get answers with timestamp citations that
play the exact moment in the original audio.

**Status:** Milestone 0 — project scaffolding.

## Setup

Requires [uv](https://docs.astral.sh/uv/).

```powershell
uv sync                          # create .venv and install locked dependencies
Copy-Item .env.example .env      # then fill in your real API keys
```

## Run tests

```powershell
uv run pytest
```
